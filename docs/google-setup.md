# Google Setup Guide for HighEnd Restoration

## 1. Google Analytics (GA4)

### Step 1: Create GA4 Property
1. Go to [analytics.google.com](https://analytics.google.com)
2. Click **Admin** (gear icon bottom left)
3. Click **Create** → **Property**
4. Name it "HighEnd Restoration"
5. Set timezone to **Eastern Time (US)**
6. Set currency to **USD**
7. Click **Next**, select business info, click **Create**

### Step 2: Set Up Data Stream
1. Choose **Web** as platform
2. Enter `https://highendrestoration.org` as URL
3. Name the stream "HighEnd Restoration Website"
4. Click **Create Stream**

### Step 3: Get Measurement ID
After creating, you'll see a **Measurement ID** like:
```
G-XXXXXXXXXX
```
**Copy this ID** - you'll need it for the website.

### Step 4: Add to Website
Give the Measurement ID to the developer to add to the site, or add it to `app/layout.tsx`.

---

## 2. Google Search Console

### Step 1: Add Property
1. Go to [search.google.com/search-console](https://search.google.com/search-console)
2. Click **Add Property**
3. Choose **URL prefix** (right side)
4. Enter `https://highendrestoration.org`
5. Click **Continue**

### Step 2: Verify Ownership

**Option A: HTML Tag (Recommended)**
1. Select **HTML tag** verification method
2. Copy the meta tag that looks like:
   ```html
   <meta name="google-site-verification" content="xxxxxxxxxxxxxx" />
   ```
3. Give this to the developer to add to the site
4. Once added, click **Verify** in Search Console

**Option B: DNS Verification**
1. Select **Domain name provider** method
2. Copy the TXT record value
3. Add it to your domain's DNS settings
4. Wait 5-10 minutes, then click **Verify**

### Step 3: Submit Sitemap
1. Once verified, click **Sitemaps** in the left sidebar
2. In the "Add a new sitemap" field, enter: `sitemap.xml`
3. Click **Submit**

Google will now crawl and index your site. Check back in 2-3 days for data.

---

## 3. After Domain Transfer

Once `highendrestoration.org` points to Vercel:

1. **Add the live domain to Search Console** as a new property
2. **Update GA4 data stream** to use the production domain
3. **Re-submit sitemap** on the new property
